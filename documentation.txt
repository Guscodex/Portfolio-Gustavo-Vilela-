
# Documentação Técnica: Portfólio Gustavo Vilela Santos
**Guia de Instalação e Configuração do Zero (Ambiente Local)**

Este documento serve como guia definitivo para desenvolvedores que desejam configurar o ambiente de desenvolvimento localmente, migrando da versão de protótipo (CDN) para uma estrutura profissional de build.

---

## 1. Stack Tecnológica

*   **Runtime:** Node.js (v18+)
*   **Framework/Build Tool:** Vite (React + SWC)
*   **Linguagem:** TypeScript
*   **Estilização:** Tailwind CSS (PostCSS)
*   **IA:** Google GenAI SDK (`@google/genai`)

---

## 2. Pré-requisitos

Antes de iniciar, certifique-se de ter instalado:
1.  **Node.js** (Versão LTS recomendada): [Baixar Node.js](https://nodejs.org/)
2.  **Gerenciador de pacotes:** npm (vem com o Node), yarn ou pnpm.
3.  **Editor de Código:** VS Code (recomendado).

---

## 3. Instalação Passo a Passo

### Passo 1: Criar o Projeto (Scaffolding)
Abra seu terminal na pasta onde deseja criar o projeto e execute:

```bash
npm create vite@latest portfolio-gustavo -- --template react-swc-ts
cd portfolio-gustavo
```

### Passo 2: Instalar Dependências
Instale as bibliotecas utilizadas no código:

```bash
# Dependências principais
npm install @google/genai

# Dependências de desenvolvimento (Tailwind e Tipos)
docker run -it --rm --entrypoint sh node:24-alpine
```

### Passo 3: Configurar Tailwind CSS
Inicialize o arquivo de configuração do Tailwind:

```bash
npx tailwindcss init -p
```

Isso criará os arquivos `tailwind.config.js` e `postcss.config.js`.

Substitua o conteúdo pelo seguinte para corresponder ao design system do projeto:

## 4. Migração de Arquivos e Estrutura

A estrutura de pastas no Vite deve ficar assim. Mova os arquivos do código atual para os locais indicados:

```
portfolio-gustavo/
├── public/
│   ├── favicon.svg
│   ├── gustavo_vilela_santos_cv.pdf
│   └── images/                  <-- Mover pasta 'images' inteira para cá
│       ├── profile.jpg
│       ├── project-saga.jpg
│       └── ...
├── src/
│   ├── components/              <-- Mover pasta 'components' para cá
│   │   ├── Header.tsx
│   │   ├── Hero.tsx
│   │   └── ...
│   ├── App.tsx                  <-- Mover App.tsx para cá
│   ├── constants.tsx            <-- Mover constants.tsx para cá
│   ├── translations.ts          <-- Mover translations.ts para cá
│   ├── types.ts                 <-- Mover types.ts para cá
│   ├── index.css                <-- Arquivo CSS criado acima
│   ├── main.tsx                 <-- Vite cria este arquivo (substituto do index.tsx)
│   └── vite-env.d.ts
├── index.html                   <-- Na raiz
├── package.json
├── tailwind.config.js
└── vite.config.ts
```

**Atenção ao `main.tsx`:**
O arquivo `index.tsx` original deve ser adaptado para o padrão do Vite (geralmente chamado de `main.tsx`):

```tsx
import React from 'react'
import ReactDOM from 'react-dom/client'
import App from './App'
import './index.css' // Importante importar o CSS do Tailwind

ReactDOM.createRoot(document.getElementById('root')!).render(
  <React.StrictMode>
    <App />
  </React.StrictMode>,
)
```

## 5. Configuração de Variáveis de Ambiente (Google Gemini)

1.  Crie um arquivo `.env` na raiz do projeto.
2.  Adicione sua chave de API:

```env
VITE_API_KEY=sua_chave_api_aqui
```
*Nota: No Vite, variáveis de ambiente devem começar com `VITE_` para serem expostas ao frontend.*

3.  Atualize o código em `components/ImageEditor.tsx` (se existir) para usar `import.meta.env.VITE_API_KEY` em vez de `process.env.API_KEY`.

---

## 6. Executando o Projeto

### Desenvolvimento Local
Para rodar o servidor local com Hot Reload:

```bash
npm run dev
```
Acesse o link fornecido no terminal (ex: `http://localhost:5173`).

### Build para Produção
Para gerar a versão otimizada para deploy:

```bash
npm run build
```
Isso criará uma pasta `dist/` com os arquivos estáticos prontos para upload.

---

## 7. Deploy

Este projeto pode ser hospedado gratuitamente em:
*   **Vercel:** Conecte seu repositório GitHub e ele detectará o Vite automaticamente.
*   **Netlify:** Arraste a pasta `dist` ou conecte o GitHub.
