
# Documentação do Projeto: Portfólio Gustavo Vilela Santos

Este documento fornece um guia completo para configurar, executar e implantar o site do portfólio localmente e em um ambiente de produção (homologação).

---

## 1. Visão Geral do Projeto

Este é um site de portfólio pessoal para Gustavo Vilela Santos, desenvolvido como uma aplicação de página única (SPA) usando React e TypeScript, com estilização via Tailwind CSS. O projeto é totalmente estático, o que significa que não requer um backend complexo para ser executado.

**Principais Características:**
- **Multi-idioma:** Suporte dinâmico para Português (pt), Inglês (en) e Espanhol (es).
- **Tema Dark/Light:** Alternância de tema claro e escuro com persistência da preferência do usuário.
- **Responsivo:** Design adaptável para desktops, tablets e dispositivos móveis.
- **Componentizado:** Estrutura organizada em componentes React reutilizáveis.
- **Otimizado para SEO:** Inclui meta tags, dados estruturados (Schema.org) e Open Graph para melhor indexação e compartilhamento em redes sociais.

## 2. Configuração do Ambiente de Desenvolvimento (Local)

Siga estes passos para executar o projeto em sua máquina local.

### Pré-requisitos

- **Node.js e npm:** Essencial para gerenciar as dependências do projeto. Você pode baixá-los em [nodejs.org](https://nodejs.org/).
- **Um Servidor Web Local (Recomendado):** Como o projeto utiliza módulos ES6 (`import`/`export`), abri-lo diretamente do sistema de arquivos (`file://...`) pode causar problemas de CORS. É recomendado usar um servidor local simples.

### Passos de Instalação via CMD (Prompt de Comando)

1.  **Clone o Repositório:**
    Abra o CMD e navegue até o diretório onde deseja salvar o projeto. Em seguida, clone o repositório do projeto. (Nota: Se você recebeu os arquivos diretamente, pule este passo e vá para o passo 2).
    ```bash
    git clone <URL_DO_REPOSITORIO>
    cd nome-do-diretorio-do-projeto
    ```

2.  **Crie a Estrutura de Arquivos:**
    Certifique-se de que todos os arquivos do projeto (`index.html`, `index.tsx`, `App.tsx`, `translations.ts`, etc.) estão na mesma estrutura de diretórios fornecida.

3.  **Instale um Servidor Local:**
    Se você não tiver um servidor local, pode instalar um facilmente via npm. O `serve` é uma ótima opção.
    ```bash
    npm install -g serve
    ```

4.  **Inicie o Servidor Local:**
    Ainda no diretório raiz do projeto (onde o `index.html` está localizado), execute o seguinte comando:
    ```bash
    serve .
    ```
    O CMD exibirá um endereço local, geralmente `http://localhost:3000`.

5.  **Acesse o Site:**
    Abra seu navegador (Google Chrome, Firefox, etc.) e acesse o endereço fornecido pelo servidor (ex: `http://localhost:3000`). O site do portfólio deve carregar.

## 4. Homologação e Implantação (Deploy)

Como este é um projeto totalmente estático, o processo de implantação é muito simples. Não há necessidade de um "build" ou compilação. Você só precisa hospedar os arquivos existentes.

### O que é um Site Estático?
Significa que o site é composto apenas por arquivos HTML, CSS, JavaScript e imagens. Quando um usuário acessa o site, o servidor simplesmente envia esses arquivos como estão. Isso torna a hospedagem mais barata, rápida e segura.

### Opções de Hospedagem

Você pode usar qualquer serviço que hospede arquivos estáticos. Algumas opções populares e gratuitas são:

- **Vercel:** Ótimo para projetos React. Conecte seu repositório Git e ele fará o deploy automaticamente a cada atualização.
- **Netlify:** Similar ao Vercel, com um processo de deploy contínuo muito simples.
- **GitHub Pages:** Permite hospedar sites diretamente de um repositório no GitHub.
- **Hospedagem Web Tradicional (cPanel):** Se você tem um plano de hospedagem tradicional, basta usar o Gerenciador de Arquivos ou um cliente FTP (como o FileZilla) para enviar todos os arquivos do projeto para a pasta raiz do seu site (geralmente `public_html`).

### Passos para a Implantação (Exemplo com cPanel)

1.  **Prepare os Arquivos:**
    Junte todos os arquivos e pastas do projeto em um único local.

2.  **Acesse sua Hospedagem:**
    Faça login no painel de controle da sua hospedagem (ex: cPanel).

3.  **Abra o Gerenciador de Arquivos:**
    Navegue até o "File Manager" ou "Gerenciador de Arquivos".

4.  **Vá para a Pasta Raiz:**
    Entre no diretório `public_html` (ou o diretório raiz do domínio onde você quer implantar o site).

5.  **Faça o Upload dos Arquivos:**
    Use a função "Upload" para enviar todos os arquivos e pastas do projeto para este diretório. Certifique-se de manter a mesma estrutura de pastas (`components/`, etc.).

6.  **Verifique:**
    Acesse o seu domínio no navegador. O site deve estar funcionando. Se você encontrar uma página de erro 404, verifique se o arquivo `index.html` está na pasta raiz correta.

Pronto! Seu site está no ar e acessível publicamente.
