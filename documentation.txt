
# Documentação do Projeto: Portfólio Gustavo Vilela Santos

Este documento fornece um guia completo para a estrutura, funcionalidades e execução do site de portfólio pessoal de Gustavo Vilela Santos.

---

## 1. Visão Geral do Projeto

Este projeto é uma **Single Page Application (SPA)** desenvolvida com **React 18** e **TypeScript**, utilizando **Tailwind CSS** para estilização. 

**Destaques Técnicos:**
- **Acessibilidade First (A11y):** Projetado para conformidade WCAG, incluindo widget de VLibras, controle de contraste/fonte e navegação por teclado.
- **Alta Performance:** Otimizado para Core Web Vitals (Lighthouse 90+), com carregamento lazy de imagens e animações leves via CSS/IntersectionObserver.
- **Sem Build Complexo:** Utiliza *Import Maps* e módulos ES6, rodando diretamente no navegador sem necessidade de transpiladores pesados (Webpack/Vite) para desenvolvimento simples.
- **Design Moderno:** Estética "Clean Premium" com gradientes mesh, texturas de ruído e padrões de grid.

---

## 2. Funcionalidades Implementadas

### Acessibilidade
1.  **Menu de Acessibilidade:** Widget flutuante (canto inferior esquerdo) que permite:
    - Aumentar/Diminuir tamanho da fonte.
    - Alternar para Modo de Alto Contraste (Fundo preto, texto amarelo/ciano).
2.  **VLibras:** Integração com o widget governamental de tradução para Língua Brasileira de Sinais.
3.  **Navegação:** Link "Skip to Content" oculto para leitores de tela e foco visível (`outline`) em todos os elementos interativos.
4.  **Semântica:** Uso correto de tags HTML5 (`<main>`, `<nav>`, `<section>`, `<h1>`-`<h3>`) e atributos ARIA.

### UI/UX
1.  **Tema Dark/Light:** Detecção automática da preferência do sistema e botão de alternância manual.
2.  **Internacionalização (i18n):** Suporte completo a Português (PT), Inglês (EN) e Espanhol (ES).
3.  **Scroll Reveal:** Componente personalizado `RevealOnScroll` que anima elementos suavemente quando entram na viewport.
4.  **Back to Top:** Botão flutuante que aparece após rolar a página.

## 4. Guia de Configuração e Execução

### Pré-requisitos
- **Imagens:** Certifique-se de que a pasta `/images` existe na raiz e contém os arquivos referenciados em `constants.tsx` (ex: `project-saga.jpg`, `profile.jpg`).

### Executando Localmente
Como o projeto usa módulos ES6 nativos via navegador, você precisa de um servidor HTTP simples para evitar bloqueios de CORS (Cross-Origin Resource Sharing).

1.  **Instale um servidor simples (se necessário):**
    ```bash
    npm install -g serve
    ```

2.  **Inicie o servidor na pasta do projeto:**
    ```bash
    serve .
    ```
    Ou use a extensão "Live Server" do VS Code.

3.  **Acesse:**
    Abra `http://localhost:3000` (ou a porta indicada) no seu navegador.

## 5. Personalização

### Adicionando Novos Projetos
Edite o arquivo `constants.tsx`. Procure pela função `getProjects` e adicione um novo objeto ao array:

```typescript
{
  image: "/images/novo-projeto.jpg",
  title: "Nome do Projeto", // Ou t.projectList[x].title para tradução
  description: "Descrição...",
  tags: ["Tag 1", "Tag 2"],
  link: "https://..."
}
```
*Lembre-se de adicionar as chaves de tradução correspondentes em `translations.ts
